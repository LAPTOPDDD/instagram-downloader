# InstaSave 1.1 — расширение для Firefox

Скачивает доступные вам видео, Reels, фотографии и элементы карусели: с отдельной страницы, из выбранного поста в ленте или по вставленной ссылке. Интерфейс на русском языке. Без сборки, npm, внешних библиотек, аналитики и стороннего сервера.

## Установка для проверки

Требуется **Firefox 128 или новее**, настольная версия.

1. Распакуйте `instagram-downloader.zip` в отдельную папку.
2. Откройте в Firefox `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение…»**.
4. Выберите `manifest.json` из распакованной папки `instagram-downloader`.
5. Откройте Instagram и **обновите вкладку**, если она была открыта до установки.
6. Найдите InstaSave в меню расширений — кнопка с пазлом. При желании закрепите на панели.

**Важно:** временное дополнение удаляется после перезапуска Firefox. Для постоянной установки в обычном Firefox нужна подпись Mozilla: автор может отправить ZIP через https://addons.mozilla.org/developers/ и выбрать самостоятельное распространение, получить подписанный XPI и установить его. Этот архив исходников не подписан; переименование ZIP в XPI не заменяет подпись. Проверка Mozilla может потребовать дополнительные сведения или изменения.

## Обновление с версии 1.0

1. Распакуйте новый архив `instagram-downloader-v1.1.zip`.
2. Откройте `about:debugging#/runtime/this-firefox` и удалите прежнее временное дополнение InstaSave.
3. Нажмите «Загрузить временное дополнение…», выберите `manifest.json` из новой папки.
4. **Обновите вкладку Instagram**, иначе в ней останется старый content script.

## Использование — карусель прямо в ленте

1. Войдите в Instagram обычным способом, если публикация требует входа.
2. Найдите нужную карусель в ленте и прокрутите до низа её блока.
3. Нажмите добавленную расширением кнопку **«↓ Выбрать для скачивания · InstaSave»**. Она не открывает вкладок и не начинает скачивание, а выбирает конкретный пост.
4. Нажмите значок расширения на панели Firefox → **«Найти медиа в публикации»**.
5. Отметьте нужные файлы или оставьте выбранными все и нажмите **«Скачать выбранное»**.
6. Проверяйте завершение в загрузках Firefox (`Ctrl+J` или меню браузера). «Передано в загрузки» означает запуск, а не подтверждение успешного завершения каждого файла.

Выбор поста действует только пока этот блок остаётся на той же странице. При переходе на другую страницу выберите пост заново. Поле ссылки в popup имеет приоритет над выбором на странице — очистите его, чтобы использовать кнопку под постом.

### Если кнопки под постом нет

Разметка Instagram различается между аккаунтами. Кнопка появляется только в блоках `article`, в которых найдена однозначная ссылка на пост. На сетке профиля или некоторых вариантах сайта кнопки может не быть.

Откройте меню поста **⋯ → «Копировать ссылку»** (или кнопку «Поделиться» → «Копировать ссылку», если такое меню есть), нажмите значок InstaSave и вставьте ссылку в новое поле. Затем нажмите **«Найти медиа в публикации»**. Instagram должен быть открыт в активной вкладке, но **переходить по скопированной ссылке и открывать новую вкладку не нужно**. Поле принимает только адрес поста `/p/…` или видео `/reel/…`, а не профиль и не короткую ссылку-переадресацию.

Обычный способ с отдельным адресом поста `/p/…` или Reel `/reel/…` также сохраняется; для него не нужно выбирать публикацию в ленте.

Обычная папка: `Загрузки/Instagram/КОД/КОД_01.mp4` (для фото — соответствующее расширение). Реальное расположение зависит от настроек загрузок Firefox. Переключатель «Спрашивать, куда сохранить каждый файл» включает диалог сохранения **для каждого** выбранного файла. Повторные загрузки не перезаписывают уже существующие файлы.

## Как это работает

1. Читает JSON-данные уже открытой страницы, ищет только выбранную публикацию по shortcode или ID. Для вставленной ссылки данные при необходимости запрашиваются у Instagram без перехода на неё.
2. Если полных данных нет, делает один GET-запрос к внутреннему `https://www.instagram.com/api/v1/media/ID/info/`, используя существующую сессию браузера. Расширение не запрашивает пароль, не извлекает cookie и не отправляет сессию на сторонние серверы.
3. Выбирает вариант с наибольшим разрешением среди предоставленных прямых ссылок. Это не гарантия оригинального файла, максимального битрейта или максимального качества, существующего на сервере Instagram.
4. Если Instagram не отдаёт данные, пробует ссылки из видимого блока публикации. В этом случае **показывает предупреждение, что полнота карусели не подтверждена**. Переключайте слайды вручную и повторяйте поиск. При повторном поиске список заменяется, а не накапливается.
5. Передаёт выбранные прямые ссылки штатному менеджеру загрузок Firefox.

## Ограничения

- Внутренний API Instagram не документирован и может меняться, требовать входа или отклонять запросы. Заголовок приложения в `content.js` не является секретным ключом и не гарантирует доступ.
- **Работа с реальным Instagram не проверена в авторизованной сессии при создании этого архива.** Выполнены локальные тесты извлечения данных, разрешённых адресов, ответов API и передачи загрузок. Реальная совместимость зависит от текущей версии сайта и аккаунта.
- Закрытые публикации можно читать только если ваша обычная сессия уже имеет к ним доступ. Обхода приватности, платного доступа, проверки возраста, авторизации и защиты от скачивания нет.
- Истории, эфиры, массовое скачивание профиля, DASH/HLS, отдельная сборка звука с видео и DRM не поддерживаются. Видео с `blob:` без доступной прямой ссылки не скачивается. Иногда Instagram возвращает только обложку: расширение не выдаёт её за скачанное видео.
- В ленте требуется явно выбрать пост кнопкой InstaSave, чтобы не скачать соседнюю публикацию. Если кнопка не появилась, используйте поле ссылки в popup. Автоматическая поддержка всех вариантов разметки Instagram не гарантируется.
- Длительность, размер файла и наличие звуковой дорожки заранее не проверяются. Скачивается тот прямой файл, который выдал Instagram.
- Ссылки CDN временные. Если загрузка завершилась ошибкой, обновите пост и найдите файлы заново.
- Нельзя скачивать произвольные внешние URL: допускаются только HTTPS-адреса Instagram, `cdninstagram.com`, `fbcdn.net` и их поддоменов.
- Используйте только для собственного контента или с разрешения правообладателя; соблюдайте правила платформы.

## Разрешения и приватность

- `activeTab`: определяет активную вкладку после нажатия на расширение.
- `downloads`: передаёт выбранные файлы менеджеру загрузок.
- `storage`: сохраняет только флажок диалога сохранения.
- Доступ к `instagram.com`: чтение данных публикации и запрос её медиа. В Manifest V3 Firefox может дополнительно запросить доступ к сайту — разрешите его в настройках расширения.
- Content script запускается на Instagram и отслеживает добавление блоков публикаций, чтобы встроить кнопки выбора. **Извлечение медиа и API-запросы выполняются только по кнопке поиска в окне расширения.** Выбранный пост хранится в памяти вкладки, вставленная ссылка — только в открытом popup.
- Предпросмотр найденных файлов может обращаться напрямую к CDN Instagram/Meta, а загрузка файлов — к тем же адресам. Нет сторонних серверов расширения, аналитики, трекинга, удалённого кода или отправки истории просмотров.

## Состав проекта

- `manifest.json` — Firefox Manifest V3 с `background.scripts`.
- `content.js` — чтение текущей публикации и резервные способы поиска.
- `media.js` — извлечение медиа, проверка URL, преобразование shortcode в ID без потери точности.
- `background.js` — проверка ссылок и последовательный запуск загрузок.
- `popup.html`, `popup.css`, `popup.js` — интерфейс.
- `icons/` — локальные значки.
- `tests/` — автономные тесты с синтетическими данными; `node tests/test.cjs`.

## Быстрая проверка вручную

- Один пост с фото → один файл; Reel → видео, не обложка.
- Смешанная карусель → фото/видео в порядке публикации, возможность снять выбор. В ленте выбрать второй пост из нескольких → запрос должен относиться именно к нему.
- Лента без выбранного поста → инструкция по выбору; сторонний сайт → понятная ошибка; вставленная ссылка работает в активной вкладке Instagram без перехода.
- API отклоняет запрос → резервный поиск с предупреждением, без скрытых повторных запросов.
- «Выбрать все», частичный выбор, диалог сохранения, закрытие popup после запуска → загрузки обслуживает фоновый скрипт.
- Перезагрузка временного дополнения → обновить страницу Instagram.
